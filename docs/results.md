# 实验结果

> 这里记录各环节的实测数字，方便复现时对照。除特别说明外，评测都在仿真里做：整条确定性播放（首帧开始、无噪声、无随机化、脚摩擦 1.0），"摔倒"与训练终止条件相同。所有结果均为单次运行（单种子），差异在 1–2 个百分点内的请视为噪声。

## 1. 数据处理

### 1.1 重定向精度

关键点平均误差：LAFAN1 BVH 0.6–2.4 cm；AMASS SMPL-X 走路 0.4–2.7 cm。

SMPL-X 朝向偏移两步修正的效果（ACCAD 走路转身 11 s，左 / 右）：

| | 只用 T 字形 | + 骨段对齐 | + 扭转标定 | LAFAN 对照 |
|---|---|---|---|---|
| 肩 | 2.1 / 1.7 cm | 0.9 / 0.9 | 0.5 / 0.5 | 0.9 / 1.0 |
| 肘 | 3.8 / 3.0 | 1.4 / 1.6 | 0.8 / 1.2 | 1.7 / 1.7 |
| 腕 | 1.7 / 1.1 | 4.1 / 3.6 | 1.1 / 1.3 | 1.8 / 2.4 |
| 膝 | 3.5 / 2.7 | 2.7 / 2.0 | 2.7 / 2.1 | 2.2 / 2.3 |

扭转角在 −20° 到 −30° 之间手臂误差都接近最小。跑步、大幅挥臂等动作手腕误差可达 5–6 cm（手臂超出 Q1 关节范围）。同一段动作的 SMPL+H 与 SMPL-X 版本重定向后关节角平均差 0.05 rad。

## 2. 训练

### 2.1 Q1 适配正确性

Q1 可微正运动学与 MuJoCo 一致到 1e-10；世界模型想象侧解析计算的省力项与仿真逐值一致。

走路基准（4 段 LAFAN 走路，共 17 min，4096 环境，早期配置、无物理随机化）：0.67 h 回报 0.80，3 h 回报 0.91，均 0 摔倒。

### 2.3 基础动作模型

发布版本 dual_v3b，在 33 h 动作库上训练（各阶段累计约 35 GPU 小时，单卡）。

**留出集（302 段，训练从未见过）**：

| 接口 / 给哪些槽位 | 回报 | 摔倒 | 手位置误差 |
|---|---|---|---|
| `E_ref`（完整参考） | 0.883 | 5.0% | — |
| `E_tele` 全部槽位 | 0.738 | 6.6% | 3.3 cm |
| `E_tele` 全部槽位，只看能用命令复现的片段 | 0.844 | 1.8% | — |

`E_tele` 的回报低于 `E_ref` 是预期的：几个命令描述不了完整的全身动作，它只能"根据有限意图生成合理动作"。只给部分槽位时的"摔倒"多为参考在下蹲 / 弯腰而机器人按命令站着，偏离参考触发了终止。

**命令测试（从站立开始，全部 0 摔倒）**：

| 躯干倾斜 | 0.034 rad |
| 双手位置 | 2.7 cm |

**鲁棒性**：推搡 0.5–2.0 m/s（站立、行走、侧移、转身）全部恢复；电机参数 ±20% 偏移下 0 摔倒，其中 kp × 1.2 时跟踪误差 × 1.35（超出"< 20%"的验收线，上真机前需要实测 kp）。

|---|---|---|---|---|

## 3. 已知局限

- **抗推不足**：训练里没有外力推搡，单段动作 1.5 m/s 推力下仍有 5–20% 摔倒；
- **训练集仍有摔倒**：`E_ref` 在训练集上约 2.3% 的片段会摔（多为起点不稳或超出 Q1 能力的动作）；
- **对电机刚度敏感**：kp 偏差 20% 时误差增加约 35%；
- **命令侧不控制脚**：踢腿、交叉步等只能通过 `E_ref` 做；
- **没有全局定位**：长距离动作会在位置上漂移，只保证"样子像"；
- **右腿仍略外撇**（前进时 8 / 12°）；
- 动作首尾补站姿、高动态子集训练、4 帧 / 10 帧参考对照、跌倒风险预测输出等尚未完成。
