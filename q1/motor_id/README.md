# Q1 电机参数

可行性检查要知道每个关节的峰值 / 额定力矩，训练要知道电机参数的名义值和随机化范围。这里把公开模型文件（`q1/q1_v3`）里能拿到的证据汇总成一个先验 `prior.npz`；有真机后可以用录数拟合收窄范围。

## 文件

| 文件 | 内容 |
|---|---|
| `joints.py` | 关节名与力矩上限参考 |
| `actuator.py` | 执行器参数化模型（PD + 前馈 → 力矩–转速包络钳位）；名义值、随机化范围、采样、读 npz |
| `prior.py` | 汇总证据 → 推断 → 写 `prior.npz`（`python prior.py`，约 1 s） |
| `prior.npz` | 22 个关节的名义值与随机化上下界（训练与可行性检查读这个） |
| `fit.py` | 离线拟合真机录数，估计各关节实际用到的峰值 / 持续力矩与力矩–转速包络（`--synth` 用合成数据自测） |
| `data/synth_passive.npz` | 合成测试数据 |

## 证据与结论

| 项 | 来源 | 名义值 | 随机化范围 |
|---|---|---|---|
| 峰值力矩 | URDF `effort`、MJCF `ctrlrange` / `actuatorfrcrange` 三处一致为 36 / 22 | 髋 / 膝 / 腰保守取 35，踝 / 臂 22 N·m | 30–35 / 18–22 |
| 额定（持续）力矩 | 公开资料未给，按一体化关节模组常见的峰值 / 额定 ≈ 3 估计 | 约 11.7 / 7.3 N·m | — |
| 空载转速 | URDF `velocity` | 36 / 32 rad/s，恒力矩区到 0.5 倍 | 28–40 / 25–36 |
| 转子惯量（关节侧） | `q1_v3_mc.xml` | 0.004 kg·m²（约为小腿连杆惯量的 11%，训练模型必须带） | 0.002–0.008 |
| 关节摩擦 | 模型给 0 | 0 | 库仑 0–0.6 / 0–0.4，粘滞 0–0.08 / 0–0.05 |

额定力矩是估计值，可行性检查和评测里的"超额定"统计只作参考；有真机录数后建议用 `fit.py` 的结果替换。

校核：1.2 m/s 行走时全身机械功率约 200 W，分摊到每个腿关节的均方根力矩约 5.5 N·m，低于额定估计，自洽；单腿屈膝 60° 久站约需 14 N·m，超过额定估计，所以长时间单腿支撑会触发热限。

训练里实际使用的执行器随机化（kp、kd、力矩上限 ±20% 等）见 [训练与评测](../../docs/training.md#14-随机化)。

## 真机录数拟合（可选）

本仓库不提供真机录数脚本。按机器人自己的接口录下全身关节状态，存成 npz：`names`（关节名）、`t`（s）、`q`、`qd`、`tau`（帧 × 关节），可选 `motor_temp`、`hz`，格式与 `data/synth_passive.npz` 相同。录数时机器人应用吊带兜住，动作的速度覆盖越广越好。

1. 拟合：`python3 fit.py data/passive_*.npz --out data/motors.npz --plot data/envelope.png`；
2. 看报告中关键关节（标 ◀）的"占上限"与"持续 1 s vs 峰值"：峰值接近上限说明录到的动作吃满了，远低于上限则需要主动激励测试才能测到上限。
